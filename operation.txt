Starting Up

At power on the Pico expect a USB cable connected to a computer
running a serial terminal program (Minicom, etc).

From now on, the term 'computer' will mean the Pi Pico based
system.

As it starts up, the computer will display some diagnostic
messages. When it is ready, it will prompt for year, month, day,
hour, minute. Enter a valid time.

More diagnostic messages will be displayed. When Running in multi
user mode you will see a prompt from the 8080 codeed operating system.

Typing a command or the <enter> key will start a login
process. Type 'login' (no quotes). At the User: prompt
type 'fred' (no quotes) and press <enter>. At the Password:
prompt type 'derf' (no quotes).

Username/password is defined in emulator_1.c in the input port 253
routine (about line 2800). This will change later. 

You will be greeted with an OS1> prompt. At this point
the 8080 program 'boot.hex' is running things. Typing 'help'
and <enter> will show the following:

Any command entered that is not a built in command is assumed to
be a compiled program resiging on the SD card. The program extension
is assumed to be .com 

If you type in 'diag' <enter> the OS will add the .com extension, load
the diag.com program into memory and begin execution. When the diag.com
program ends, it will jump to address 0x0000 which jumps to the boot.hex
start address. All user compiled programs start at location 0x100 (decimal 256).

The computer is NOT currently set up to run CP/M programs. Likely this will
change in the future.

There is no special shutdown proceedure. Just turn off power.

File operations are atomic among users. While a file is being created, updated
etc from the SD card, all other operations stop. Typically this is so fast
that other users will not notice a slowdown. Also, the file system is mounted
and unmounted for all file operations. At the end of a file process 
all pointers and files are closed so other users cannot damage files in-use.
